## 🚀 Progetti in evidenza

### 🎮 [LoL Jungle Assistant](https://github.com/Francesco0603/lol-jungle-assistant)

Assistente real-time per la **Champion Select di League of Legends**, sviluppato in **Python**.

Analizza automaticamente la composizione alleata e quella avversaria e valuta diversi jungler attraverso un **motore di scoring euristico spiegabile**, basato su caratteristiche strategiche come engage, frontline, DPS, burst, peel e controllo degli obiettivi.

**Tecnologie:** Python, SQLite, League Client local API, Requests, psutil

**Caratteristiche principali:**
- lettura real-time della Champion Select
- riconnessione automatica al League Client
- database strategico dei champion
- analisi della composizione alleata e avversaria
- bilanciamento danno fisico/magico
- scoring spiegabile
- test tramite scenari controllati

### 🎯 [Guess the Sentence](https://github.com/Francesco0603/guess-the-sentence)

Applicazione **full-stack** sviluppata per il corso di **Web Applications I** del Politecnico di Torino.

Il progetto implementa un gioco di frasi da indovinare con autenticazione, sessioni persistenti, timer, valuta virtuale, statistiche utente e modalità demo, attraverso una vera architettura client/server.

**Tecnologie:** React, Vite, Node.js, Express, SQLite, Passport, React Bootstrap

**Caratteristiche principali:**
- frontend React con routing e componenti riutilizzabili
- backend REST con Node.js ed Express
- autenticazione e gestione sessioni con Passport
- password protette con scrypt e salt per utente
- persistenza dati con SQLite
- logica di gioco lato server
- modalità autenticata e demo
- gestione timer, timeout e abbandono partita
